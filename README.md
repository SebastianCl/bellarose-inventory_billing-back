# bellarose-inventory_billing-back

___

## Bellarose - Inventory and Billing

Aplición de inventario y facturación.
___

### Instalación 🔧

Se requiere [NodeJS](https://nodejs.org/) v10+ para correr.
Instale las dependencias y devDependencies:

```sh
cd bellarose-inventory_billing-back
npm install
```

### Ejecución ⚙️

Iniciar el servidor.

```sh
npm start
```

Vera un mensaje confirmando el inició:

```sh
Server is up and running on port number 3435
```
